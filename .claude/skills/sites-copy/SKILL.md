# Sites Copy — Estratégia, Frameworks e Revisão

Pipeline completo de copy para websites em 3 camadas: **estratégia de conteúdo** (o que dizer e onde) → **frameworks de copywriting** (como dizer) → **revisão editorial** (garantir qualidade antes de entregar).

## 1. Estratégia de conteúdo

### Hierarquia de mensagens

```
Nível 1 — Core Message (1 frase)
    "Fazemos X para Y obterem Z"
    Ex.: "Automatizamos o financeiro para PMEs fecharem o mês em 1 dia"

Nível 2 — Pilares de suporte (3-5 pontos)
    Cada pilar suporta o core message
    Ex.: "Integração bancária automática" / "Conciliação sem planilha" / "Relatórios em tempo real"

Nível 3 — Provas (por pilar)
    Dados, depoimentos, casos, screenshots
    Ex.: "3.200 empresas fecham o mês 5x mais rápido" + logo wall
```

Toda página deve responder, nessa ordem: **o que é → para quem é → por que confiar → o que fazer agora**.

### Arquitetura de conteúdo por página

**Home**
1. Proposta de valor principal (hero: headline + subheadline + CTA)
2. Para quem é (audiência nomeada explicitamente)
3. Como funciona (3-4 passos ou pilares)
4. Prova social (logos, números, depoimentos)
5. CTA para próxima ação

**About**
- Origem e missão (StoryBrand: cliente = herói, marca = guia)
- Valores (3-5, cada um com 1 frase de descrição concreta)
- Equipe (opcional)
- CTA de contato ou produto

**Produto/Serviço**
- Problema que resolve (na linguagem do cliente)
- Como resolve (feature → benefício, nunca feature solta)
- Casos de uso concretos
- Preços (se aplicável) + FAQ (objeções reais)
- CTA de compra ou contato

### Tom de voz por setor
- **Saúde:** empático, claro, sem jargão
- **Tech/SaaS:** direto, orientado a resultados
- **Moda/Lifestyle:** aspiracional, sensorial
- **B2B:** profissional, orientado a ROI
- **Educação:** encorajador, claro, acessível

## 2. Frameworks de copywriting

### AIDA (landing pages, hero sections)
- **A**ttention: headline que para o scroll
- **I**nterest: subheadline que explica o benefício
- **D**esire: body copy que pinta o "depois"
- **A**ction: CTA específico e orientado ao resultado

### PAS (páginas de produto, e-mail)
- **P**roblem: nomear o problema exato do cliente ("Você perde 2 dias por mês conciliando extratos")
- **A**gitate: amplificar a dor ("E cada erro vira retrabalho no fechamento")
- **S**olution: apresentar como a saída lógica ("Conciliação automática em minutos")

### BAB (seções de transformação, cases)
- **B**efore: o estado atual doloroso
- **A**fter: o estado desejado alcançado
- **B**ridge: o produto como ponte entre os dois

### 4Ps (páginas de venda longas)
- **P**romise: a promessa central
- **P**icture: pintar a vida com o resultado
- **P**roof: prova (dados, depoimentos, garantia)
- **P**ush: empurrão final com urgência legítima

### StoryBrand (About, brand pages)
- Cliente é o **Herói** — marca é o **Guia**
- Sequência: herói tem problema → conhece guia → guia dá plano → herói age → sucesso (e o fracasso evitado)

## 3. Headlines e CTAs

### Fórmulas de headline
- `[Resultado desejado] sem [objeção principal]` — "Site novo no ar sem contratar agência"
- `Como [benefício] em [tempo] — mesmo se [situação desfavorável]`
- `A razão pela qual [grupo] [resultado inesperado]`
- `[Número] [coisa] que [transformação]`

### CTAs que convertem

| Objetivo | CTA fraco | CTA forte |
|---|---|---|
| Trial | "Registrar" | "Começar grátis hoje" |
| Demo | "Contatar" | "Ver demo de 15 min" |
| Compra | "Comprar" | "Garantir o meu lugar" |
| Download | "Download" | "Obter o guia gratuito" |

Regra: o CTA descreve o **resultado** que o clique entrega, não a ação mecânica.

### Regras de tom
- Frases curtas ganham (máx. 20 palavras)
- Segunda pessoa ("você") > terceira pessoa
- Especificidade > generalidade ("reduza 40% do tempo" > "ganhe eficiência")
- Benefícios > features (feature só entra amarrada ao benefício)

## 4. Checklist de revisão editorial

Rodar **antes de entregar qualquer copy**:

### Clareza
- [ ] Proposta de valor compreensível em 5 segundos
- [ ] Sem jargão não explicado
- [ ] Frases com menos de 20 palavras (maioria)
- [ ] Um pensamento por frase

### Persuasão
- [ ] Headline usa uma das fórmulas testadas
- [ ] Benefícios explícitos (não apenas features)
- [ ] CTA descreve resultado, não ação
- [ ] Objeções principais antecipadas (FAQ, garantia, prova)

### Consistência
- [ ] Tom de voz uniforme em toda a página
- [ ] Terminologia consistente (mesmo nome para a mesma coisa)
- [ ] Pessoa gramatical consistente (2ª pessoa "você")

### Técnico (PT-BR)
- [ ] Sem erros ortográficos, acentuação correta
- [ ] Sem anglicismos desnecessários
- [ ] Pontuação correta

### Erros comuns a eliminar
- "Somos líderes de mercado" → sem prova = vazio
- "Alta qualidade" → específico como?
- "Solução inovadora" → clichê total
- "Estamos aqui para você" → não diz nada
- Começar com o nome da empresa → começar com o cliente
